# Malinge & Associés — site vitrine

Menuiserie & agencement sur mesure, Le Pin-en-Mauges (49). Astro 5 + Tailwind 4, déployé sur Vercel.

```bash
npm install
cp .env.example .env   # PUBLIC_WEB3FORMS_KEY, GOOGLE_PLACES_API_KEY
npm run dev
```

Voir `CLAUDE.md` pour les conventions (photos, données) et `docs/brief-site.md` pour le brief.
